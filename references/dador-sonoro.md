# Dador sonoro

El Dador teje modelos. El Maestro materializa el oido.

```
vision (poema)
  -> formula de toma (letra etiquetada + style box)
      -> generador (Suno / MakeSong / Voice)
          -> WAV + HPF 170
              -> piso (limpia | tech | organica) 118 Dm
                  -> stems + master
```

MakeSong entra solo en el nodo de toma o de clip. Nunca en el nodo de graves.
